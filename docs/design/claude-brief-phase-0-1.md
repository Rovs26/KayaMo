# Claude design brief — Mus Phase 0–1

You are lead designer. Visual source: **KayaMo mobile app design (5)** tokens (390×844, Day blue/white, Night aubergine/lime, seed habitat, IBM Plex Mono eyebrows, Barlow clocks). Product authority: `Mus_Build_Source_of_Truth.md`. If a pretty layout fights that file, the file wins.

The current PWA still looks like a tracker. This pack **replaces the sitemap**, not the craft.

## Companion and name

- App name on chrome: **KayaMo** (product name TBD later).
- Companion: **Mus**. Seed illustration stays. Mus is present on Home in the atmosphere (habitat + optional short speech cloud). Do **not** use a floating puck that overlaps content.

## Five tabs (fixed)

1. **Home** — Daily Command Center  
2. **Goals**  
3. **Life**  
4. **Grove**  
5. **Mus**

No center **+** tab. Capture is **Life Inbox** on Home (one field / sheet).

### Home — stable core (must not reshuffle)

- Date + greeting  
- Mus habitat + restrained Grove/XP chip  
- Day Intent / capacity (optional, compact)  
- Today’s top priorities + timeline/list  
- Life Inbox capture  
- Plan My Day / Restructure / Rescue (can be one primary + overflow)  
- One active goal card (“Working toward”)  
- Evening reflection entry  

Adaptive cards may change **prominence**, not the skeleton.

### Goals

Empty → talk with Mus / write myself → blueprint (goal, why, done-looks-like, first step) → active (stats, next step, trail) → pause / **set down (Released)** / it happened. Setting down is not failure and takes no XP away.

### Life

Area list. Hidden areas stay gone without rebuilding the app. First deep area: **Physical Self** (food, weight, gym — reuse Health hierarchy). Other areas: quiet shelves, “set up later”.

### Grove

Seed → Sprout → Sapling → Growing tree → Mature tree. Presence, what produced progress, Life Story later. Dormant/tired is allowed. Death, XP loss, and a single Life Score are not.

### Mus

Full conversation as a **tab**, not the only UI. Citations when numbers come from records. **Remember this** is explicit. Footer: Mus proposes; the user confirms every write.

## Phase 0–1 screens to draw (this pack)

Onboarding: “Who are you trying to become?” then skippable life areas, then first plan — not a five-step health formula as the front door.

Also: Plan My Day proposal (editable), Minimum / Rescue, Weekly Reset v1, What Mus knows / can do (simple), come-back-after-a-bad-day (no overdue dump).

## Do not design yet

Circles/social, partner rewards, app blocking, wearables, résumé generator, wall-to-wall calendars, lock-screen marketing mocks as product UI.

## Copy

No cheat / guilty / burn it off / bad food / sinful. Rest is valid. Missed days do not erase the grove.
